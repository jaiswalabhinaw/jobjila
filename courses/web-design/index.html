Syllabus

8 modules across 8 weeks, at roughly 6 hrs/week.

Design foundations

Layout, hierarchy, type and colour — the difference between a page that looks amateur and one that looks paid for.

Figma for practical design

Wireframes, components and a design a client can approve before you write a line of code.

HTML & CSS properly

Semantic structure, flexbox and grid, and modern responsive CSS without a framework crutch.

Responsive & mobile-first build

Image optimisation, Core Web Vitals, alt text, heading structure and meta tags that help the site get found.

Domains, hosting & handover

DNS, SSL, deployment, backups, and the handover document that stops clients calling you at midnight.

Frequently asked questions

What are the website designing course fees?

₹12,500 for 8 weeks, including live sessions, recordings, Figma practice files and hosting for your capstone project for the first year.

Do I need to know programming before joining?

No. This course assumes no prior coding at all. HTML and CSS are taught from the very first tag, and the no-code track means you can deliver paid client work even before you feel fluent in code.

Will I learn JavaScript in this course?

Only lightly — enough for interactive menus, sliders and form validation. The focus here is design and delivery. Learners who want to go deeper into JavaScript usually follow this with a front-end development track.

How soon can I take on freelance website projects?

The no-code and WordPress modules land in week five, and many learners take their first small paid project around then. Your capstone site doubles as the portfolio piece you show prospective clients.

Is WordPress still worth learning?

For the Indian small-business market, yes — it remains the fastest way to deliver a maintainable site at a price a local client will actually pay. We teach hand-coded and WordPress delivery together so you can choose per project.
