IT Infrastructure & Networking

The layer everything else runs on, and the most dependable door into IT.

Book the free first class Syllabus

Every company that owns a laptop needs someone who understands infrastructure. This course builds that foundation properly — networking, servers, identity and virtualisation — and remains one of the most dependable routes into an IT career without a computer science degree.

Syllabus

8 modules across 10 weeks, at about 6 hrs/week.

How networks move data

The OSI model made practical: IP addressing, subnetting, DNS and DHCP, with packet captures you can actually read.

Routing and switching

VLANs, static and dynamic routing, and building a small multi-site network in a simulator.

Server administration

Windows Server and Linux side by side — users, permissions, file shares, scheduled jobs and patching.

Active Directory and identity

Domains, group policy and single sign-on, the backbone of nearly every corporate IT estate.

Virtualisation

Hypervisors, virtual machines, snapshots and resource planning with VMware and Hyper-V.

Backup, recovery and continuity

Backup strategies, RTO and RPO, and actually restoring from a backup under time pressure.

Security hardening and monitoring

Firewalls, VPNs, endpoint protection, and reading logs to spot a problem before users report it.

Capstone: design a small-office IT estate

Deliver a full network diagram, server plan, backup policy and cost sheet for a 40-person company.

What you will be able to do

  • Subnet a network correctly without a calculator
  • Build and manage a Windows domain with group policy
  • Design a backup plan you have personally tested a restore from
  • Diagnose connectivity faults methodically instead of by trial and error
  • Present a complete small-office infrastructure design

IT Infrastructure & Networking — questions

Is this enough to get an IT support job?

It covers what entry-level IT support and infrastructure roles screen for: networking fundamentals, Windows and Linux administration, Active Directory and structured troubleshooting. Combined with the capstone and mock interviews, learners typically target IT Support Engineer or Network Administrator roles.

Does this prepare me for CCNA?

The routing, switching and networking modules cover a substantial part of the CCNA foundation. It is not a CCNA exam-cram course — the goal is working competence — but learners who go on to CCNA find the groundwork already done.

Do I need my own hardware?

No. All practical work is done in simulators and remote labs we provide. A laptop with 8 GB of RAM and a stable connection is enough.

Should I do this or a cloud course first?

If you are completely new to IT, do this first. Cloud sits on top of networking and server concepts, and people who skip the foundation usually have to come back to it.
