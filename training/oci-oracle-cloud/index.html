Oracle Cloud Infrastructure (OCI)

The cloud with the least competition for jobs — and a growing enterprise install base.

Book the free first class Syllabus

Oracle Cloud is smaller than AWS and Azure, and that is precisely the opportunity. Companies running Oracle databases and E-Business Suite are moving them to OCI, and there are far fewer trained people competing for that work. If you want a cloud skill where you are not the thousandth applicant, this is it.

Syllabus

7 modules across 8 weeks, at about 6 hrs/week.

OCI architecture and tenancy model

Regions, availability and fault domains, compartments, and the tenancy structure that makes OCI governance different from AWS and Azure.

Identity and access management

Compartments as a security boundary, groups, dynamic groups and policy statements — OCI's policy language written from scratch.

Compute and storage

Compute shapes including flexible shapes, block volumes, object storage tiers, and the file storage service.

Virtual Cloud Network

VCNs, subnets, route tables, security lists and network security groups, internet and NAT gateways, and connectivity back to on-premise.

Databases on OCI

Autonomous Database, Base Database Service and MySQL HeatWave — what each is for and how they are provisioned and backed up.

Observability, cost and migration

Monitoring, logging, budgets and cost analysis, plus how a typical Oracle-to-OCI migration is actually planned.

Capstone: build a governed OCI tenancy

Design compartments, policies, network and a database workload, then document the architecture as a migration proposal.

What you will be able to do

  • Structure an OCI tenancy with compartments and policies that hold up
  • Write OCI IAM policy statements without copying from documentation
  • Build a VCN with correct segmentation and controlled egress
  • Provision and back up an Autonomous Database
  • Sit the OCI Foundations Associate exam, and prepare for Architect Associate

Oracle Cloud Infrastructure (OCI) — questions

Is OCI worth learning when AWS and Azure are bigger?

For job-market maths, often yes. There are fewer OCI roles overall, but there are far fewer trained candidates — so the ratio can be better than AWS. It is particularly strong if you have any Oracle database background, or want to work with companies running Oracle applications.

Are Oracle certification exams free?

Oracle has periodically offered free certification windows for OCI exams, but this changes without notice, so we do not build a promise around it. Assume you will pay Oracle directly, and we will tell you if a free window is open when your cohort runs.

Do I need to know Oracle Database for this course?

No. The database module explains what Autonomous Database is and how to run it from a cloud infrastructure point of view. Deep SQL and DBA work is a separate skill and not required here.

Can I practise OCI for free?

Yes. Oracle's Always Free tier is unusually generous — it includes compute instances, block and object storage, and two Autonomous Databases that do not expire. Almost the entire course can be practised at no cost.
