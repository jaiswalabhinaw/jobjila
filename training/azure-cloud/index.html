Cloud Platforms

Microsoft Azure

The cloud most Indian enterprises already run — and the one their IT teams hire for.

Book the free first class Syllabus

If a company already runs Microsoft 365, Windows Server and Active Directory, its cloud is almost always Azure. That describes a very large share of Indian enterprises and their captive centres — which is why Azure administration is one of the steadiest hiring lines in Indian IT.

Syllabus

7 modules across 10 weeks, at about 6–8 hrs/week.

Azure architecture and governance

Regions, resource groups, subscriptions and management groups, plus how Azure billing and cost allocation are structured.

Compute and storage

Virtual Machines and scale sets, managed disks, Blob and File storage tiers, and choosing between them on cost and access pattern.

Virtual networking

VNets, subnets, network security groups, peering, VPN gateway and Azure Load Balancer — built hands-on, not on slides.

Identity with Microsoft Entra ID

Users, groups, roles, conditional access and hybrid identity with on-premise Active Directory. This is the module that most distinguishes Azure from AWS.

Governance, policy and backup

Azure Policy, RBAC, resource locks, Recovery Services vaults, and a backup you have actually restored from.

Monitoring and cost management

Azure Monitor, Log Analytics, alerts, budgets and reservations — including how to present a cost reduction to management.

Capstone: design and deploy a governed environment

Build a complete subscription with correct identity, network segmentation, policy, backup and cost controls, then document it.

What you will be able to do

  • Deploy and manage Azure VMs, storage and networking end to end
  • Configure Entra ID including roles and conditional access
  • Apply Azure Policy and RBAC so an environment stays compliant
  • Build and test a backup and recovery plan
  • Sit AZ-900 with confidence, and prepare for AZ-104

Microsoft Azure — questions

Do I need Windows Server experience before this Azure course?

It helps but it is not required. The identity module covers Active Directory concepts from the beginning, since hybrid identity is where most Azure work actually happens.

Is AZ-900 or AZ-104 the right certification for me?

AZ-900 is a fundamentals exam and is achievable for everyone who completes this course. AZ-104 is the administrator associate exam and is the one employers actually value — the course covers its syllabus, and most learners sit it a few weeks after finishing.

Are the Microsoft exam fees included?

No. Exam fees are paid directly to Microsoft. We prepare you and guide the booking, but the fee itself is not ours.

Can I use a free Azure account for the labs?

Yes. Azure's free account plus its always-free services cover most of the course. We set up budget alerts in week one so nothing runs up a bill without you knowing.
